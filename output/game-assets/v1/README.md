## 文件规格、来源与导出

全部生产PNG为sRGB；不透明背景alpha全255，透明素材外边≥8px全透明，最长边≤1536。源图与锚点/资源包/命名按清单保留。

使用内置image_gen逐项生成。源母版位于 `source-masters/`；本轮提示词与实际参考文件见 `production-round2.json`，上一轮提示词见 `production-prompts.json`。按钮无参考新绘；受损状态以已完成H-01为编辑目标；武器参考H-01与母港；场景以日光概念及简版为风格基准。

导出使用CoreGraphics：等比缩放、居中/侧边对齐、透明留边；不拉伸、不重绘、不覆盖原概念稿。新透明素材多数先裁去多余空画布，裁框以alpha>2的边界外扩8源像素确定；极淡的alpha≤2外部杂点可能被裁掉，主体形状不变。左右礁壁分别左/右对齐。`asset-index.csv`记录每项crop和alignment，源母版不裁改。

`export-assets.py`在当前版本会调用 `reexport-selected.py`，可仅靠包内母版重导出27张成品；输出像素发生变化时重置为待视觉检查。`export-round2.py`是本轮生产记录的导出入口，依赖其原始生成路径；交付使用包内母版重导出入口即可。Pillow只用于尺寸/alpha检查与裁框测量，PNG导出和验收拼版由Swift/CoreGraphics完成。
