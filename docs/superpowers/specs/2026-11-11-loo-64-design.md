# LOO-64 潜航终端视觉与返港设计

任务已明确授权基于既有风格主动优化。本设计由实现者选择，直接执行，不扩大玩法；基线 `81a2f8c`（含 `906d5e6`）。所有构建和证据另存 LOO-64，不修改 LOO-59/62 证据与线上发布。

## 方向与取舍

采用深海工业潜航终端：海军蓝钢板、黄铜切角、青色航图刻线，主行动用暖金，次行动用暗钢；标题带舱室编号与图标，列表用分隔线、部件插槽与等级刻度。按下、选中、不可用状态分别表现。保留既有原创船体、场景、敌人与图标。

参考 DREDGE 的港口功能分区、船体居中及明确出航行动；参考 DAVE THE DIVER 的场景优先和紧凑状态信息。只借鉴信息层级，自行制作边框/航图与物体造型，不下载或复制他人素材。参考入口：https://store.steampowered.com/app/1562430/DREDGE/ 、https://store.steampowered.com/app/1868140/DAVE_THE_DIVER/ 。

考虑过全屏卡片重排（仍显网页且削弱场景）及重制全部场景贴图（不必要的范围/加载风险）。选择统一 Cocos 原生绘制语言与既有素材组合。

## 面板清单

母港首页、机体强化、科技分支、装备/合成确认、补给（馈赠/祝福/声呐/珍珠箱）、任务、档案、海报、母港加载/错误；潜航 HUD、低氧供给、暂停、死亡救援、返回/结算、广告/奖励确认、断线/后台/倒计时、海域加载/重试。全部使用统一切角钢板框架与行动层级。

首页：顶部港名/等级与一行货币；中央船体和航图；任务/档案为次入口；底部唯一主要下潜按钮和四个养成入口。馈赠、祝福、声呐归入补给，取消首页重复出航按钮。教程提示直接指向强化入口，保留教学逻辑。

短屏审查修正：列表面板只保留一个纵向 ScrollView；短屏装备采用收纳列表/单件详情/三合一确认三个同面板子视图，避免把内层虚拟列表包进外层滚动。合成仍先展示精确消耗和返还再确认。只有海报/档案等非列表内容使用整体滚动，关闭留在固定标题区。

## 行为

手动上浮：曾实际潜入水下后，到 0m 的那个逻辑步不立即结算；在后续逻辑步保持主动向上累计 0.35 秒才走既有 requestReturn → arriveHarbor → settle。松手/转向/暂停会清除累计；初始 0m 未下潜不可触发。声呐自动方向不计为主动上浮。新增可选检查点字段记录曾下潜，旧检查点按深度/最深纪录推断；不恢复未完成的上浮累计。死亡优先，结算幂等沿用现有服务。

岩壁：屏幕位置由统一镜头绝对 y 驱动；近景与远景使用不同滚动比例；循环瓦片带交叠并交替镜像消除接缝；没有基于时间的岩壁漂移。每层加载/窗口重排后使用同一绝对相位。装饰岩壁无碰撞；已有可碰撞礁石仍按统一投影绘制。

## 素材清单

敌人/精英/Boss/船体：保留已接入 SpriteFrame 与泳动序列，不再增加占位回退。碰撞礁石：保留 LOO-62 不规则切面岩体。荧晶拾取：圆点换为带亮暗晶面的晶簇。水雷：圆点中心换为金属雷体、端盖、触角和示灯。已开放裂隙：椭圆换为断裂岩门与发光通道。气泡、悬浮粒子、摇杆、深度标记、声波和爆炸范围有明确语义，保留。新增形状均为原生 Graphics 向量资产，高低档同轮廓，无新增位图或图集负担。
