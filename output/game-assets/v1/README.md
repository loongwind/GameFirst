## 来源与复导出

使用内置image_gen逐项生成；本轮完整提示词、参考路径与生成源路径见`production-round3.json`，前两轮分别见`production-prompts.json`、`production-round2.json`。选定母版均保存在`source-masters/`，原概念稿与原型参考未覆盖。失败按钮稿在`rejected/`，不计作生产资源。

生产PNG位于`main/`、`sunlight/`、`meta/`。一般透明静态图保留≥8px透明边，游动横条按每格≥2px特例，细填充条按上述已裁决特例。其余规格与原交接文档一致，实际最长边≤1536。

`export-assets.py`调用`reexport-selected.py`，依据索引使用包内母版与排版JSON复导出；支持标准静态、细条三段切片、四帧横条三种格式。若导出像素变化，会将对应状态重置为待视觉复查。Swift/CoreGraphics负责PNG/GIF与拼版导出；Pillow仅检查像素、测量裁框与锚点，不生成或编辑成品图像。
