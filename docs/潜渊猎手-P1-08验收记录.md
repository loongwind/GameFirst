# P1-08 新手引导与任务系统验收记录

基线 `5d0f67d`，分支 `loo-57-tutorial-tasks`。保留 P1-01～07 成果，变更限教学、目标、纪录海报及对应集成/回归。

## 实现

- 新存档从 Boot 直接进入真实 Dive。0–10 秒自动战斗；10–30 秒摇杆移动、击杀与拾取；30–60 秒依次提示舱容与氧气；60 秒后提示主动返航；真实卸货后在母港强化舱容或氧效一次，再次出发即完成第六步并自由探索。有效潜航时间驱动教学，广告/资源/后台暂停不会快进。
- 教学局使用明确的 `spawnIntervalTicks=90`（普通局为15），原生命、伤害、武器、成长和掉落均保留。普通密度的初次实测约27秒死亡，因此单独调整教学遭遇节奏；该配置随原局检查点恢复，完成教学后的新局回到普通配置。
- 首次合格教学返航通过原 `EconomyService.dispatch(dive.settle)` 原子发放固定500荧晶；领取键 `tutorial:first-deposit:v1` 只消费一次，替代该局荧晶拾取，不额外叠加。其他材料与实际击杀XP遵循原规则。早退或死亡不会伪造教学完成。重放跑真实潜航→强化→再潜，只保留正常局收益。
- 轮换任务按“累计1000m → 击杀3渊主 → 玩家等级50”的顺序展示，使用 `rotation-v1:<序号>:<目标>` 实例键；三项领完后不凭空重复发奖。每任务成功领取增加配置中的20XP。首日三潜为独立任务，实例键绑定首个业务日。
- 资格来自持久化战斗检查点/最终结算：累计深度按每个原 diveId 的最大到达深度增量计，渊主按原局已击败身份计；首日仅真实击杀后主动返航并完成最终结算计数。救援继续同局，重复检查点/不同opId/重复点击均不增加计数或奖品。遥测伪事件和任意外部资格回调不能生成任务资格。
- 每500m写入一次打卡；纪录保存实际深度和该局已遇生物身份。安全返港后自动展示本地生成的750×1100 PNG，数字、海水背景和生物剪影均以Canvas程序绘制，预览使用本地data URI，保存经PlatformAdapter交给浏览器下载。没有运行时AI、网络图片或伪造小程序码。
- 教学/深度事件通过P1-04 TelemetryBus提交后发布，带原dive_id；任务累计独立于遥测待上传队列，清除已确认遥测不清除资格。dive_start、dive_end、deposit_done沿用原领取/结算去重入口。
- UiScope管理面板、按钮、订阅与PNG纹理释放；目标列表滚动、重放按钮固定在面板安全范围内，覆盖375宽下667/750/812高度与44/34安全区。基础自动攻击常开，原广告token重试、情境暂停、绝对到期契约保留。
