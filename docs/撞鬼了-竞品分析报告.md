## 二、核心玩法拆解

### 2.1 操作与战斗

左下虚拟摇杆移动，武器全自动索敌攻击；穿戴的武器（飞剑、弩、斧等）直接悬浮显示在角色周身，战力成长可视化。周期性自动释放大范围技能（环形剑阵 AOE、天降巨剑/万剑诀类特效）。

### 2.2 局内循环

进图探索 → 自动割草/打碎酒坛瓦罐 → 掉落金币 → 拾取填入「钱袋」（如 0/45.21K 持续增长）→ 钱袋有容量上限 → 经右侧「传送」回祭坛上缴 → 金币投入局外养成 → 战力提升 → 推进更深地图

**「钱袋-上缴 + 死亡清袋」是核心风险回报设计（实证）**：

- 背包容量即单次资源上限，玩家面临「继续深入贪怪 vs 及时回城落袋」的持续决策
- **死亡代价（实证）**：角色死亡后**钱袋清空**，并自动复活回老家——贪刀的代价是清袋，及时上缴的收益是落袋保住，风险决策两侧均成立
- 容量可通过养成扩容：「容量」属性（35.03K→35.55K）、「虚空口袋」经书（+16%→+17%）、天师赐福「行囊符」（+20%，限时）多路并行
- 推论（标注推断）：容量成长的价值是单次运更多、摊薄往返成本；但袋内未上缴金额越大，死亡清袋的损失敞口也越大——容量成长与风险敞口同步放大，是该机制的张力与深度所在

### 2.3 局外养成四层

1. **锻体**（金币直购属性）：力量/容量/生命/生命恢复/暴击率/移速，等级上限极高（如力量 230/2000），典型长线数值坑；升到特定等级需消耗蓝珠/红珠（实证）
2. **进阶**（经脉 + 经书）：打坐人形经脉图，节点依次点亮（熟练→化明→开脉→闭脉→玄冥…），下阶奖励百分比属性（力量%+5%、技能冷却-5%）；经书（筋骨重铸/金刚经/虚空口袋/嗜血经）消耗蓝珠/红珠，最多 15 级
3. **装备**（暗黑like）：主手 4 槽 + 2 槽（56 级/81 级解锁），装备带等级与品质（灰/绿/紫），支持品质排序、装备最佳、快速合成——即《弹壳特攻队》验证过的合成玩法
4. **图鉴**（收集）：按地图分组统计每种妖怪击杀数，进度可一键领取元宝奖励

### 2.4 地图与怪物

至少 5 张地图按难度递进——乱葬岗 → 封门村 → 幽竹林 → 幽暗沼泽 → 地府前庭（截图时仅部分解锁，未解锁妖怪以灰色剪影留悬念）。每图怪物分三档：普通（蓝框）→ 精英（紫框）→ 妖王（红框），全图鉴约 40+ 种妖怪（灯笼妖、伞妖、僵尸王、飞头蛮、黑无常、判官、牛头马面罗刹等），题材统一且设计量充足。

### 2.5 目标系统

主界面右上角轮换任务条（「角色等级达到 50 级 48/50」「击杀任意妖王 2 次 0/2」），持续给短期目标。

## 三、系统与 UI 结构

主界面单屏高密度布局：

- 顶部：等级徽章 + 金币/元宝/绿玉三货币栏 ｜ 右上任务条
- 左列：「天师赐福」「战令」
- 右列：「传送」「自动(未激活)」
- 底栏：「商店 / 挑战(等级锁) / 锻造(x/90) / 装备 / 提升」＋ 左下「图鉴」

所有养成入口一屏直达，红点引导密集（9 个入口中 6 个挂红点）。挑战入口带铁链锁（等级门槛），锻造入口显示 x/90 进度 + 绿玉数量。

## 四、商业化与留存

### 4.1 商业化模式定论

**纯 IAA**：唯一收益为微信流量主广告分成，无任何 IAP 内购（需求方确认；佐证：全部解锁/领取按钮均为标准激励视频图标，游戏内未见任何充值入口与价格锚点）。

### 4.2 激励广告点位全景（终稿）

| 点位 | 位置 | 机制（实证） | 喂养对象 | 类型 |
|---|---|---|---|---|
| 随机福利 | 主界面左下金币图标 | 看广告 → 随机奖励（金币、能量珠、元宝等） | 全养成线补充渠道 | 增益型 |
| 天师赐福 | 左列 | 看广告 → 三选一符咒 buff（金币+10% / 背包容量+20% / 经验+10%），各 20 分钟，0/2 次数 | 局内割草效率 + 升级速度 | 增益型 |
| 自动攻击 | 右列 | 看广告 → **10 分钟**自动寻敌+攻击，限时授权非永久 | 解放双手 | 便利型 |
| 锻造 | 底栏「免费 5/5」 | 绿玉（材料）锻造武器；材料用尽可看广告继续锻造，免费次数计数 5/5 | 装备产出线 | 便利型 |
| 战令 | 左列 | 领取奖励；可看广告领取额外奖励（奖励含元宝） | 留存 | 增益型 |
| 商店 | 底栏 | **武器箱抽卡制：广告免费抽（白银 3/10、黄金 3/3）＋ 元宝抽取并行**（白银 50/次、500 十连；黄金 100/次、1K 十连）；黄金箱带「再抽 10 次必得史诗武器」保底；产出武器 + 武器升级券 | 装备获取 + 元宝消耗端 | 增益型 + 消耗端 |
| 复活 | 局内死亡结算（情境触发） | 看广告 → 原地复活、**钱袋不清空**（默认死亡则清袋+回城复活） | 止损（保住本局收益） | 止损型 |

> 注：顶栏「更多游戏」为微信小游戏平台机制，不纳入本竞品分析。

**点位计数口径（终稿统一）**：主界面 5 个直接入口（随机福利 / 天师赐福 / 自动 / 锻造免费 5/5 / 商店）＋ 战令按「面板入口 / 广告加领」计 2 个 = **7 常驻**，另有复活 1 个**局内情境型**点位，合计 **7 常驻 + 1 情境 = 8**。

### 4.3 点位密度分析

- **主界面同屏 5 个直接广告入口**，加战令共 7 个常驻广告触点；红点引导与广告点位高度重叠
- **单日广告次数理论天花板**：赐福 3 符 × 2 次 = 6 次 + 免费锻造 5 次 + 武器箱免费抽（白银 3 + 黄金 3）+ 自动（10 分钟/次，单次会话可续）+ 随机福利（次数未知）→ 活跃用户单日 10+ 次激励视频轻松可达
- **点位性质三类光谱**：增益型（赐福/随机福利/战令加领）、便利型（自动/锻造续锻/免费抽）、**止损型（复活）**。复活是**死亡惩罚与广告变现的直接耦合点**：默认死亡代价（清袋）恰好构成广告复活的价值锚点——惩罚越痛，广告越值钱，是纯 IAA 设计里负反馈与变现耦合的典型案例
- **设计原则**：主界面几乎所有功能性入口都已广告化，且以「增益/加速」为主；buff 时长（20 分钟 / 10 分钟）短于典型游戏时段，制造高频复看。自动攻击做成 10 分钟限时授权而非永久解锁，把「便利」切成**可重复售卖的最小单位**——纯 IAA 产品 LTV 公式（DAU × 人均广告次数 × eCPM）的标准打法
- **「玩法产进度、广告喂加速」模型**：核心进度货币（金币/绿玉/蓝红珠）的主动产出均在局内玩法，广告覆盖养成全链条但定位是「高覆盖度的可选加速」，不构成「不看广告就卡死」的进度墙
- **风险面**：第三方「免广告版」渠道的存在（第六节）说明高频广告是双刃剑——该产品选择了激进的纯 IAA 路线，收入效率与用户流失压力并存

### 4.4 货币体系（终稿）

六类资源，分层隔离产出与消耗：

| 货币/道具 | 产出 | 消耗 |
|---|---|---|
| 金币 | 局内割草掉落（经钱袋上缴） | 锻体属性（特定等级需蓝/红珠） |
| 元宝(银) | 图鉴击杀进度、商店看广告领取、**BOSS 掉落（少量）、战令广告加领、随机广告福利** | 商店抽取武器箱（白银 50/次、500 十连；黄金 100/次、1K 十连） |
| 绿玉 | 局内掉落 | **锻造武器材料（实证）** |
| 蓝珠 | 精英怪掉落（部分精英掉蓝）＋ 随机广告福利 | 进阶经书、锻体/经络特定等级门槛 |
| 红珠 | 精英怪掉落（部分精英掉红）＋ 随机广告福利 | 高阶经书（嗜血经需蓝+红）、锻体/经络特定等级门槛 |
| 武器升级券（道具） | 武器箱开出 | 武器升级 |

### 4.5 元宝闭环（终稿）

**图鉴击杀进度 / 看广告（商店领取、战令加领、随机福利） / BOSS 掉落 → 元宝 → 抽武器箱（白银/黄金）→ 武器 + 武器升级券**

- 元宝是**广告与装备线之间的中间货币**：5 个产出渠道中 3 个直接挂钩广告，装备获取的两条线（锻造、抽卡）各有广告入口（看广告续锻 / 广告免费抽）——**装备线是五条养成线里广告渗透最深的一条**
- 白银箱免费上限 10 次、黄金箱仅 3 次——白银箱拉广告频次，黄金箱配合保底卡稀有度节奏；元宝可通过广告免费获得，给非付费用户「氪度替代」路径，是纯 IAA 下抽卡商业化的标准解法
- 商店的双角色：**既是广告位（免费领取/免费抽），也是核心货币的消耗端**——广告位与货币闭环在同一入口交汇

### 4.6 留存钩子

每日任务（杀妖王 2 次）、战令、图鉴长线收集、等级解锁（50 级目标/56 与 81 级装备槽/挑战门槛）。天师赐福 0/2 次数、锻造免费 5/5、武器箱免费抽均为**日清式计数**，与每日任务共同构成每日回访理由清单。

## 五、亮点与不足

### 亮点

1. **题材差异化**：志怪僵尸×道士在幸存者like 中辨识度高，暗黑水墨美术在 Q 版卡通扎堆的小游戏大盘里质感突出，本身就是买量素材卖点
2. **钱袋-上缴 + 死亡清袋经济（实证完整）**：资源上限 + 落袋决策 + 死亡惩罚 + 广告复活救援，构成完整的风险回报循环，节奏与决策感优于同类纯挂机
3. **图鉴击杀计数**：把刷怪本身变成收集目标，长线留存组件成本低、见效久
4. **装备可视化**：穿戴即悬浮展示，每一笔养成投入都肉眼可见
5. **养成分层清晰**：四层养成各自独立产出渠道，广告/肝度可分层承接不同用户

### 不足/风险

1. **主界面入口过载**：一屏 9+ 入口、红点泛滥，新手认知成本高，红点易麻木
2. **局内操作深度有限**：视频全程仅移动+自动战斗；「自动」未激活时手动收益感弱，激活后局内又近乎放置——两头不讨好的风险
3. **无社交/排行榜可见**：素材内未见任何社交、好友、排行元素，小游戏长线留存最大抓手缺失
4. **武器槽仅 4+2 但武器种类多**（刀剑斧弩镖镰），可能稀释合成聚焦度
5. **体量信号弱**：第三方渠道千级下载、零公开数据，推测未起量（产品仍在打磨期或买量能力不足）

## 六、市场背景（联网检索）

- 2025 年国内小游戏市场收入 535.35 亿元，同比 +34.39%，占游戏大盘 15%（游戏工委/华福证券口径）
- 2026 年 1-5 月微信小游戏变现收入同比 +20%；IAA 小游戏月活 4 亿（70% 为纯休闲玩家），IAP 小游戏月活超 3 亿、占大盘 60%，人均时长 +8%、日均启动 8 次（2026 微信小游戏开发者大会）
- 幸存者like 至今是小游戏热门品类（《弹壳特攻队》《行侠仗义》等长期在榜），装备合成玩法已被充分验证
- 结论：品类赛道仍在红利期，但头部固化，「题材差异化 + 美术质感」是中小团队切入该品类的主要打法，「撞鬼了」正是这个打法的典型样本

## 七、对我们产品的可借鉴建议

（基于我们在做微信小游戏产品的假设，若定位不符请指正）

1. **玩法公式直接可复用**：大盘验证玩法（幸存者like/割草）× 差异化题材（民俗志怪、地域传说等）的空隙组合，是被「撞鬼了」这类产品验证的低风险切入点
2. **借鉴「钱袋-上缴 + 死亡清袋惩罚 + 看广告原地复活」组合**：没有死亡代价的钱袋机制只是资源上限，有代价有救援才是完整的风险回报循环——死亡清袋制造真实损失感与决策张力，广告原地复活把「止损」变成变现点。建议核心循环设计评审时四件套一次配齐：钱袋上限 → 落袋决策 → 死亡清袋 → 广告复活；并同步设计复活定价与死亡频率的平衡（复活太贵则弃疗、太廉价则惩罚失效）
3. **图鉴击杀计数系统**：强烈建议作为 MVP 后第一个长线留存组件——开发成本低，把日常刷怪行为全部转化为可见进度
4. **自动挂机 = 高频短时广告位（已实证）**：竞品以看广告解锁 10 分钟自动攻击——非永久、非当日，把便利切成可重复售卖单位。建议采用同款「短时限时授权」：单次授权时长略长于平均单次会话（如 15 分钟），配主界面固定入口，坐稳人均广告次数基本盘；同时让手动操作在战斗上限上仍有收益（走位躲技能/集火），避免纯放置化后玩法空洞
5. **控制入口密度**：首屏入口建议 ≤7 个，红点只给「今日必做」，避免「撞鬼了」式的全红点麻木
6. **多货币分层但不过量**：多货币是拉长养成线的有效手段，但每种货币必须有稳定可感知的产出场景，否则变挫败感
7. **补上社交短板作为超车点**：竞品缺失社交/排行，我们若在早期就加入好友协作或地区排行，即是差异化
8. **美术质感即买量素材**：水墨志怪风在信息流里的点击竞争力，建议美术投入向「前三秒画面冲击力」倾斜

> **商业化模型总注脚**：「玩法产进度、广告喂加速」是本次竞品验证的核心模型——核心养成货币的主动产出留在局内玩法，广告定位为全链条的增益、便利与止损（含复活），避免做成「不看广告就卡等级」的进度墙，兼顾广告频次与流失风险。
