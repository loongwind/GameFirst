# P1-07 三海层内容集成验收记录

基线 `6268158`，任务分支 `loo-56-three-sea-content`。保留 P1-01～06 的母港、经济、双槽存档、暂停与情境广告契约。未修改 `output/game-assets/v1/` 源稿。

## 内容与运行行为

- `SeaContent.ts` 的身份表覆盖 24 普通（8/8/8）、8 精英（3/3/2）、4 渊主。强度读 `ENEMY_TUNING`，四武器读 `WEAPON_DEFAULTS`；掉落、成长、科技节点读现有 shared balance。2400m 端点仍是第24带。
- 800m 鮟鱇王、1600m 裂隙守望者、2400m 流光巨鱿为主关口，2200m 巨鲸为深渊额外遭遇。主关口守卫未击杀时限制下行；恰在边界时保留守卫所属层与 Bundle，击杀后切入下一层。稀有奖励和裂隙按同一 diveId 的检查点恢复，重复击杀/刷新不重复发放。
- 六属性、五系科技、八种装备接入真实 HP、伤害、冷却、移动、舱容、氧耗、索敌和拾取；装备与特殊科技的首版可调映射见 `潜渊猎手-战斗养成数值.md`。活动局恢复沿用原武器与属性。延长射程同步延长声波和鱼雷有效寿命，避免能索敌却打不到。
- 32 种游动动画按战斗 tick 每5tick切一帧，即30Hz下6fps；暂停时动画冻结。Boss使用 r9 的768px主体坐标、512px部件画布、锚点、缩放和角度组合。
- 旧检查点缺少身份时，表现层确定性选择当前层同档真实素材，保持旧战斗数值；避免版本升级后敌人不可见。

## 资源与预算

`npm run assets:sea` 使用 Pillow 从生产索引生成85张有界纹理及稳定 Cocos meta。`game/sea-assets.json` 记录每张源 SHA、导入路径、尺寸、字节与36身份/4 rig映射。最长边1125px，关闭裁边和自动动态合图以保留四帧格子与Boss接点。

| Bundle | 导入PNG字节 | release实际下载字节（含配置/脚本） | RGBA8纹理估算字节 |
|---|---:|---:|---:|
| sunlight | 1,583,962 | 1,612,445 | 7,356,312 |
| twilight | 1,506,174 | 1,534,817 | 7,356,312 |
| abyss | 1,521,388 | 1,549,941 | 8,503,192 |
| dive（公共潜艇） | 39,838 | 41,756 | 147,456 |

三层均低于下载目标（2/4/4MiB）。最多持有当前层及移动方向的相邻层，远层释放引用；最重相邻组合+潜艇约15.27MiB RGBA8，不包含引擎、主帧缓冲、HUD和母港。Bundle少量元数据允许由引擎缓存，不持有远层纹理。构建浏览器检测深渊单层驻留时，日光层 SpriteFrame 缓存为空。

加载失败提供重试，当前资源未就绪时独立 `assets` 暂停冻结战斗与氧耗。异步过期加载、返港中销毁、同 Bundle 快速重访和部分目录加载失败均有回归。释放只配对当前画面 `addRef/decRef`，避免强制释放全局共享 Bundle；部分加载失败使用锁定 Creator 3.8.8 的引用计数清理入口。

实际构建用例先以默认战斗配置在浅层击杀3只、拾取11荧晶并卸货。随后明确注入经济资源/XP测试夹具，通过真实经济命令逐项强化六属性至100级、解锁科技、抽取/升级/挂载装备，再按普通移动输入保持距离，使用配置伤害下潜到2400m。未覆盖战斗HP或伤害。该成长夹具用于验证接入链路，不代表自然游玩养成耗时或最终经济节奏。

完成时生命约13,096/15,178、荧晶3,638、珍珠8、渊核4；四渊主及三裂隙均已记录。刷新恢复同一 diveId 后珍珠仍为8，再正常卸货返母港。800/1600/2400边界、三层48px身份和四Boss均由实际Cocos WebGL渲染截图，JSON保留属性、检查点与下载证据。

构建回归曾发现 Cocos loose 编译将 Set/迭代器展开变成错误数组，导致检查点出现 `{}`；已改用 `Array.from`，实际构建刷新测试覆盖此路径。另修复 Cocos销毁子节点后表现层重复清理，以及旧保存身份缺失导致的隐形敌人。

截图与JSON输出于测试产物目录，经任务附件交付。导入器依赖Pillow；源素材、重复工作副本与工作区 AGENTS.md 均不纳入提交。
