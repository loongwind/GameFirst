# P1-05 母港与养成 UI 验收记录

2026-11-10；基线 `3ddb4a9`；任务分支 `loo-54-harbor-ui`。

母港使用真实 Cocos Creator 3.8.8 场景与 Button/ScrollView/Mask/Widget。Boot 的“进入母港”可进入 Harbor；出发进入 Dive，结算确认按钮返回母港。原型节点映射至 HarborRoot/SubDisplay、Wallet、TaskStrip、LaunchButton、BottomNav、OverlayRoot。面板由运行时节点工厂生成，不依赖静态 Prefab 的人工绑定。

## 素材与释放

所有美术来自 `output/game-assets/v1/meta/`；原件未改。`game/tools/prepare-harbor-assets.py` 生成有像素上限的运行时副本，`game/harbor-assets.json` 记录源SHA256和尺寸。发布meta目录实际2,083,776 bytes（1.987 MiB），低于3 MiB；UI原始RGBA纹理估算8,400,792 bytes，低于本任务16 MiB持有预算。31个SpriteFrame及数字字体在场景退出后decRef，异步加载失败/离场分支也释放成功加载的部分；关闭面板立即解绑按钮/滚动/模型监听并销毁虚拟行。

原始meta交付中没有数字字体，补充 `fonts/digits.fnt` 和数字图集供钱包计数使用；中文与混排说明使用系统字体。强化页以文字表达耐压/氧气/舱容，不引用meta目录不存在的专用图标。

wechatide首次状态检查已登录、openid存在、技能版本equal，但查询小游戏AppID返回“需要重新登录”；现有WXML评审壳为touristappid。本轮没有把评审壳当正式工程打开/编译，也未进行微信模拟器、微信真机或发布验收。
