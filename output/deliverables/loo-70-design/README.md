# LOO-70 阶段一设计交付

离线打开 `index.html`。七屏可切换，顶部可查看默认/加载/空/错误状态，以及1.2秒跨层示意；这些是评审按钮，不是正式游戏UI。图片已内嵌，单独下载HTML也可查看。设计使用现有美术加CSS效果，没有生成最终新素材，没有修改游戏代码。

- `design-board.png`：R2七屏设计拼版。
- `harbor-r2-375x667.png`：375×667母港实尺寸设计截图。
- `asset-list.csv`：R2共27项，15张必出PNG、10项复用/代码、2项条件出图（暂不制作）。
- `direction-audit.csv`：36身份朝向映射，当前无需新增怪物朝向图。
- `create-design.py`：清单生成源（需从仓库根运行）。
- `verify-design.cjs`：使用仓库game/node_modules/playwright与本机Chrome检查图片、7屏、状态切换、跨层重放、390px无横向溢出，并生成拼版。

完整设计说明：`docs/潜渊猎手-LOO70-优化设计方案.md`。

验证：六入口≥44×44、无重叠、三枚红灯可见，四类养成面板分别一步返回母港；HTML全部图像解码、无JS错误、七屏导航与错误/默认状态、过渡按钮、390px宽度通过。设计稿不执行经济交易、不模拟实际战斗、不构成60fps或无缝换层性能验收。R2已参考issue补充截图底部可见的独立场景物件，取消共用底栏。新增三件码头装置仅复用素材与代码组合，meta预算不增加。四类内屏标题栏可一步返回母港。
