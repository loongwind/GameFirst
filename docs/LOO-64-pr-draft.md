潜航界面存在网页卡片堆叠、拾取/水雷占位感、岩壁静止，以及到水面仍无法手动返港的问题。本变更基于 `loo-62-mobile-combat`，将母港和全部原生面板统一为切角潜航终端，聚焦一个下潜入口，改用有语义的晶簇/金属雷体/岩门，并让近远岩壁随统一镜头滚动。

曾下潜后，到 0m 再继续主动向上 0.35 秒沿原安全返航与持久结算链路入港；松手、出生静止、声呐自动上浮、暂停/广告和死亡不会误返港。保留旧检查点兼容及结算幂等性。短屏列表保持单层纵向滚动，装备合成在独立确认页完成；全部关键按钮按实际 CSS 视口补偿。
