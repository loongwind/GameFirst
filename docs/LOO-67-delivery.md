# LOO-67 模拟广告与日光层调优

分支 `loo-66-ads-difficulty`，基于 `loo-64-dive-experience@63a006b`。模拟广告实现 `cd6c597`，加载取消修复 `d510ddc`，首层实现 `25a2bfd`，验收断言 `589664d`，HUD标识修复与最终构建 `9c809fa`。LOO-65 无 P1 返修；原未跟踪文件与固定证据未纳入提交。

## Part A：可静态部署的演示广告

`npm run build:web:preview` 先构建并检查 release，再复制到 `build/web-preview`，仅向副本增加 `preview/preview-ads.js`、CSS 和常驻“演示版 · 模拟广告”标识。`assets/` 与 `shared/` 不导入模拟驱动。release 同时接受源码依赖图与产物文案/文件名检查。

流程为加载 → 明确收入免责声明 → 三秒前台倒计时 → completed；跳过返回 skipped，不扣次数、不奖励。失败通过原 AdService 重试和取消链路。每个驱动绑定原场景，场景销毁/pagehide 的加载取消不能重新弹广告；隐藏页面不推进倒计时。没有修改奖励、死亡、清舱、token 或保存契约。

| 点位 | 验证行为 |
| --- | --- |
| gift（5/日） | 实际点击、完成仅奖励一次、跳过不奖、刷新保持、耗尽 |
| blessing（2/日） | 收益/氧气/舱容三种选择；跨日覆盖第三种，原有效期/倍率不变 |
| sonar（6/日） | 母港和潜航入口、十五分钟、耗尽；60秒续期边界另由真实服务单测覆盖 |
| silver（3/日）/gold（2/日） | 实际开箱、次数扣减；按原抽取规则验证装备或升级券，黄金保底不变 |
| oxygen（3/日） | 真实低氧资格、完成回满、耗尽 |
| rescue（3/日） | 真实死亡事件资格、完成恢复50% HP、耗尽 |

三种视口为 320×640、375×667、390×844；实际测量七种入口和 DOM 跳过按钮的点击区域，均至少44 CSS px。广告覆盖层暂时覆盖战场，关闭后 HUD 恢复；顶部标识不接收指针事件。

基础广告改为 Lv.1 开放，银/金箱与装备仍为 Lv.8。自然养成测试前两局等级为 2→4→5；实际操作中少击杀可能仍为Lv.1，因此使用Lv.1保证入口可体验。初次入账后打开补给即可看到入口，无需注入资源。

## Part B：同策略新存档结果

`newcomer.smoke.mjs` 在真实 Cocos 产物上运行，压缩战斗时钟，资源、结算、升级和广告资格仍走真实服务。前20局关闭广告。最终驱动在每次场景首次更新前冻结时钟，并断言每局从tick零开始，避免浏览器加载帧抖动。

历史130局报告是“首局两次死亡、第125局首门、最深1504m”，不能与修正驱动后的零死亡直接比较：旧脚本点击已移除的 `tutorial-next`，且受伤上浮会触发新出水返港。新驱动在基线与候选中对称改为真实强化/出航按钮、明确血量返航、配置派生的首领强度，并保持同样的操纵和升级策略。历史文件未被覆盖。

130局回归（开启原每日限额广告，非无限救援）完成130局，最深1600m，首门为第16局；暮光/深渊渊主均未被击杀。相同修正驱动下旧构建130局最深800m，历史旧策略记录1504m，候选同时超过两者。救援使用3次、补氧3次，总数受原每日限额约束，无浏览器错误。暮光/深渊参数完全保留；首层配置前后表见 `潜渊猎手-战斗养成数值.md`。
