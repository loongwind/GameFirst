# 潜渊猎手原型实施计划

日期：2026-11-09。输入：PRD、技术选型报告、三张 v1 概念稿、LOO-45 当前交接评论。

## 交付方式

采用可离线打开的 Canvas 交互原型，共享纯 JavaScript 状态模型与绘制层；另提供 WXML/WXSS/JS 小程序预览壳。正式产品仍按 Cocos Creator 3.8 的场景、Prefab 和 CloudBase 契约实施。预览壳用于设计验收，不作为正式小游戏工程。已有概念稿原样复用，不生成或拆出新图片。

完整搭建 Cocos 工程会将本轮扩展为游戏研发；静态图无法检查风险决策和异常反馈。因此本轮以共享 Canvas 原型承载页面结构和交互，并交付 Cocos 节点映射。

## 重点检查

1. 重复点击结算不会增加两份余额。
2. 弹窗、广告、切后台冻结氧气；取消广告保留原选择。
3. 低氧持续掉血而非立即死亡；救援每日上限 3 次。
4. 断网收益待确认，恢复后原操作仅结算一次。
5. 小屏底部按钮、微信胶囊区域与摇杆不会互相遮挡。
