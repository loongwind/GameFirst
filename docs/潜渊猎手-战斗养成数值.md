LOO-56 本地战斗养成映射。只在新潜航出发时计算，活动局恢复使用检查点中的属性、武器、移速和拾取半径；港口新成长不会改写同一 diveId。

六属性沿用 `shared/config/balance.json` 的 `attributeValue`：生命、舱容直接取值，攻击按初始20的比例乘武器伤害，攻速按初始1的比例缩短冷却并四舍五入到30Hz整数tick（至少1tick）；移速3m/s映射为120世界单位/s。氧效不增加120秒当量储量，而按属性增幅降低消耗。

五系科技按已解锁节点的配置 `effect` 相加，每节点只计算一次：攻击乘伤害，生存乘生命，氧气降低消耗，舱容乘容量；特殊系增加索敌/连锁距离及拾取距离。特殊系每100%增加40世界单位拾取半径。此版本未把特殊系映射到尚未上线的捕捉、卸货距离或自动战斗授权时长。

特殊科技及探照灯扩大鱼雷射程时，鱼雷寿命至少为 `ceil(新射程÷弹速×30)` tick，并保留初始60tick的下限，确保目标在配置射程内能被实际命中。特殊系20节点合计210%，鱼雷射程从400增至1240世界单位，对应至少89tick飞行寿命。

装备战斗细则在 `CombatLoadout.ts` 的 `COMBAT_GROWTH` 表配置。品质索引为0–4，单件增益 = 10% + 品质×25% + (等级−1)×2%。两个主槽初始声波/鱼雷，装备覆盖对应主槽并乘该武器伤害；八种模板只有处于已装备状态时生效，背包道具不生效。四类武器完整读取 `WEAPON_DEFAULTS`：声波环形、鱼雷直线、电弧连锁、浮雷范围引爆，保留各自射速/弹速/跳数/范围等差异。探照灯乘索敌与连锁范围（声波寿命同步延长），潜流鳍乘移速，装甲片乘生命，磁铁增加40×(1+单件增益)世界单位的拾取半径。装备增益与属性/科技乘算；相同辅件的增益相加。槽位遵守经济命令的0/1主武器、2/3辅件约定，装备8级解锁、第4槽40级解锁；先保留显式槽位，再将只有equipped标记的旧装备分配到首个空闲兼容槽。locked是合成保护标记，不影响已装备道具的战斗增益。

以上装备增益及特殊系具体战斗用途是PRD未逐项指定部分的首版可调参数，不改变经济费用、五品质、八模板、两主武器两辅件的既有契约。
